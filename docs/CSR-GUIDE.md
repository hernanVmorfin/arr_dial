# Comfort Dial: CSR guide

A customer calls with a code like **SVC20-7K3PK** from the Comfort Dial on our website. The first part names the
gift (SVC20 is $20 off any service, DUCT50 is $50 off duct cleaning, YEAR is the free year, and so on). Older codes
look like ARR-7K3P and work the same way.

## When they call

1. **Find the code.** Search the Instant Pricing Leads board in Monday for the code. It's in the item name:
   "Comfort Dial SVC20-7K3PK: $20 off any service".
2. **Check the phone.** The code is tied to the mobile number on the item. It should match the caller, or the
   person the appointment is for.
3. **Check it's still good.**
   - **Code status** must be `Issued`, not `Redeemed`.
   - **Expires** (in the item's notes) must not have passed.
4. **One per household.** Search the board for their street address. If another Comfort Dial item at that address
   is already `Redeemed`, the home has used its gift. Explain that it's one per household.
   - A **free year** is already tied to the home on the item. It has to be that address.
5. **Put the service address on the item** if it isn't there.
6. **Book the job and apply the gift in Sera.** The discount line to use is on the item, under **Apply in Sera**
   (and on the code in the Codes tab). Mind the conditions in the gift's description: duct cleaning is whole-home
   only, the water heater must be installed by ARR, the free service call waives the $129 trip fee with repairs at
   book price, and the free year is for the home on the item.
7. **Set Code status to `Redeemed`.** This marks the code used and stops their reminder texts.

## The Codes tab (CSR login)

Ask an admin to add you to the team as a **CSR**. Sign in at alwaysreadyrepair.com/dial/admin with the email and
temporary password they give you, then change the password under your name (top right).

The Codes tab does steps 1 to 3, 6 and 7 in one place:

- **Search** by code, phone number, first name or street. You can type the code loosely (`svc20 7k3pk` works).
- If you mistype or mishear **one character**, it says "one character is off": read the code back with the customer.
- Open a code to see its **status**, **expiry**, the **Sera line** to apply, the phone and address.
- **Mark redeemed** once the gift is applied in Sera. Monday's Code status changes to Redeemed and the reminder texts
  stop. Add the job number in the note.
- **Text it again** if they lost the text (up to 3 times a day).
- A **Void** code was cancelled: don't honor it. An **expired** code can't be redeemed; if it should be, ask an admin
  to extend it. Voiding, extending and exporting are for admins.

## Good to know

- Codes can't be combined with other offers and have no cash value. Most last 30 days from when they were claimed;
  a promo can last longer or shorter, so go by the expiry on the item or in the Codes tab.
- If they lost their code: find their phone number on the board. The code is in the item name. An admin can
  text it to them again from the Codes tab, and so can you with a CSR login.
- If a customer says they didn't get a text, search the board for their phone number. If the item is there, read
  them the code. If there's no item, they didn't finish claiming; take care of them by phone as usual.
- Questions about the promotion: the official rules are at alwaysreadyrepair.com/dial/rules.
